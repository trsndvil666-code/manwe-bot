# مانوه سولیمو — ربات نقش‌آفرینی حرفه‌ای

ربات تلگرامی که به‌عنوان **مانوه سولیمو** (پادشاه والار) در گروه نقش‌آفرینی می‌کند.

### ویژگی‌ها
- شخصیت بسیار دقیق و عمیق بر اساس پرونده‌ای که طراحی کردی
- شوخ‌طبعی متعادل + گاهی کمی گستاخ
- خودجوش بودن متوسط
- حافظه بلندمدت برای هر کاربر
- تشخیص نقش‌های مختلف (فئانور، ملکور، سائورون و ...)
- فقط فارسی ادبی و فاخر
- کاملاً رایگان (با Groq)

---

## پیش‌نیازها

1. یک ربات از [@BotFather](https://t.me/BotFather) بساز و توکن بگیر.
2. **حتماً Privacy Mode را خاموش کن**:
   - به BotFather برو → `/mybots` → رباتت → Bot Settings → Group Privacy → **Turn off**
   - بعد ربات را از گروه حذف کن و دوباره اضافه کن.
3. یک حساب رایگان در [console.groq.com](https://console.groq.com) بساز و API Key بگیر.
4. شناسه عددی تلگرام خودت را پیدا کن (با ربات‌هایی مثل @userinfobot).

---

## راه‌اندازی سریع (پیشنهادی: Railway)

### ۱. فایل‌ها را آماده کن
این پوشه را به صورت یک ریپازیتوری GitHub آپلود کن (یا از همینجا دانلود کن).

### ۲. در Railway:
1. برو به [railway.app](https://railway.app) و ثبت‌نام کن (با GitHub).
2. New Project → Deploy from GitHub repo
3. ریپوی خودت را انتخاب کن.
4. در بخش Variables این مقادیر را اضافه کن:

```
TELEGRAM_BOT_TOKEN = توکن ربات
GROQ_API_KEY = کلید گروک
GROQ_MODEL = openai/gpt-oss-120b
SPONTANEITY = 0.32
ADMIN_IDS = شناسه_عددی_تو
```

5. Deploy را بزن.
6. بعد از بالا آمدن، ربات را به گروه اضافه کن.

> نکته: مدل‌های رایگان Groq ممکن است تغییر کنند. اگر مدلی کار نکرد، از لیست مدل‌های رایگان در کنسول Groq یکی دیگر انتخاب کن.

---

## دستورات ادمین

| دستور | توضیح |
|-------|------|
| `/setrole` | تعیین نقش یک کاربر |
| `/whoami` | دیدن نقش فعلی خودت |
| `/start` | پیام خوش‌آمدگویی |

**نحوه تعیین نقش:**
- روی پیام فرد ریپلای کن و بنویس:  
  `/setrole فئانور`
- یا:  
  `/setrole 123456789 فئانور`

---

## تنظیمات اختیاری

در فایل `.env` یا Variables:

- `SPONTANEITY=0.32` → بین ۰ تا ۱ (هر چه بالاتر، پر حرف‌تر)
- `GROQ_MODEL` → مدل مورد استفاده

---

## نکات مهم برای کارکرد خوب

1. Privacy Mode **حتماً** خاموش باشد.
2. ربات را بعد از خاموش کردن Privacy دوباره به گروه اضافه کن.
3. ادمین‌ها را در `ADMIN_IDS` درست وارد کن.
4. برای شخصیت‌های اصلی گروه از همان ابتدا `/setrole` بزن.
