# مانوه سولیمو | ربات نقش‌آفرینی آردا

نسخهٔ بازطراحی‌شدهٔ ربات تلگرام مانوه، با پاسخ‌گویی طبیعی‌تر فارسی، شوخی و کنایهٔ کنترل‌شده، حالت‌های احساسی متنوع، شناخت نقش کاربران و راهنمای دانش‌نامه‌ای جهان تالکین.

## فایل‌ها
- `bot.py` — ربات تلگرام، حافظهٔ SQLite و اتصال Groq
- `prompts.py` — شخصیت مانوه، قواعد لحن، راهنمای روابط و دانش‌نامهٔ فشردهٔ آردا
- `requirements.txt` — وابستگی‌ها
- `Procfile` — فرمان اجرا در Railway
- `railway.json` — تنظیمات اجرای Railway

## راه‌اندازی در Railway

1. کل محتویات این پوشه را در ریشهٔ یک GitHub repository قرار بده.
2. در Railway یک پروژه از GitHub repository بساز.
3. در بخش **Variables** این متغیرها را اضافه کن:

| متغیر | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather |
| `GROQ_API_KEY` | کلید API از Groq |
| `GROQ_MODEL` | شناسهٔ مدل فعال در حساب Groq؛ پیش‌فرض `openai/gpt-oss-120b` |
| `ADMIN_IDS` | شناسه عددی ادمین‌ها، با کاما برای چند نفر |
| `SPONTANEITY` | احتمال پاسخ خودجوش بین ۰ تا ۱؛ پیش‌فرض `0.12` |
| `TEMPERATURE` | میزان تنوع پاسخ؛ پیش‌فرض `0.88` |
| `MAX_TOKENS` | حداکثر توکن پاسخ؛ پیش‌فرض `750` |
| `BOT_REPLY_ONLY_WHEN_ADDRESSED` | برای پاسخ فقط هنگام منشن/ریپلای `true`؛ پیش‌فرض `false` |

4. Deploy را اجرا کن. Railway با `Procfile` ربات را اجرا می‌کند.
5. برای اینکه ربات پیام‌های عادی گروه را ببیند، در BotFather از مسیر Bot Settings → Group Privacy، حالت Privacy را خاموش کن و ربات را یک‌بار از گروه خارج و دوباره اضافه کن.

## دستورات
- `/start` — معرفی مانوه
- `/setrole نام_شخصیت` — در پاسخ به پیام کاربر، نقش او را ثبت کن.
- `/setrole شناسه_عددی نام_شخصیت` — ثبت نقش با شناسهٔ عددی
- `/whoami` — نمایش نقش ثبت‌شده
- `/forgetme` — پاک‌کردن حافظهٔ شخصی ذخیره‌شده دربارهٔ خودت

نمونه:
- روی پیام کاربر ریپلای کن و بفرست: `/setrole فئانور`
- یا: `/setrole 123456789 گندالف`

## نکته دربارهٔ دانش تالکین
`prompts.py` یک دانش‌نامهٔ فشرده و راهنمای زمینه‌ای دربارهٔ کیهان‌شناسی، والار و مایار، درختان، سیلماریل‌ها، دوران‌ها، نژادها، زبان‌ها، مکان‌ها و شخصیت‌ها دارد. این فایل برای بهتر کردن پاسخ‌هاست و متن کامل کتاب‌ها یا یک پایگاه دادهٔ بی‌نقص و تضمین‌شده نیست. مدل زبانی ممکن است در جزئیات کم‌ذکرشده خطا کند؛ پرامپت به آن دستور می‌دهد در موارد نامطمئن حدس نزند و اختلاف نسخه‌ها را مشخص کند. برای دانش کاملاً مرجع و قابل جست‌وجو در سطح همهٔ فصل‌ها، بعداً می‌توان یک پایگاه دادهٔ lore جداگانه و قابل بازیابی (RAG) به پروژه افزود.

## حافظه و حریم خصوصی
داده‌ها در فایل SQLite با نام `manwe_memory.db` ذخیره می‌شوند. در Railway برای ماندگاری حافظه پس از deploy مجدد، یک Volume متصل کن و متغیر `DB_PATH` را روی مسیری داخل همان Volume بگذار؛ مثلاً `/data/manwe_memory.db`.
